# Досье: информация о персонаже

Одностраничный интерактивный сайт на React и Vite. На GitHub Pages публикуется автоматически после каждого push в `main`.

## Запуск локально

```bash
npm ci
npm run dev
```

## Публикация

GitHub Actions собирает проект и выкладывает его на GitHub Pages. Адрес сайта:

https://alesiakolomiiets-lgtm.github.io/interactive-character-bingo/
